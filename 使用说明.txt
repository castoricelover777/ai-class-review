课堂心得评阅工具 · 使用说明
================================================

【这个工具做什么】
学生把课堂心得发在微信群里，您把群聊记录复制粘贴进来，
工具会自动拆出「谁写了什么」，交给 AI 按您设定的规则打分，
您在表格里核对、改分，最后一键导出 Excel 成绩表。


【第一次使用：三步】
1. 双击「课堂心得评阅工具.exe」。
   会跳出一个黑色窗口（这是程序本体，别关），随后浏览器自动打开操作界面。

2. 点右上角「设置」，把 API Key 粘进去，点保存。
   - API Key 需要您自己去大模型服务商申请（例如 DeepSeek 官网）。
   - 接口地址和模型名一般不用改，默认是 DeepSeek。
   - 保存后会写在程序旁边的 config.ini 里，下次不用再填。

3. 回到主界面：
   ① 把微信群里复制的聊天记录粘贴到左边大框里；
   ② 点「解析预览」，核对一下学生姓名；
   ③ 点「开始 AI 打分」，等进度条走完；
   ④ 在结果表里改分、填评语，点「导出 Excel」。


【没填 API Key 也能用吗】
能，但是「演示模式」：分数是按字数和语言特征估的占位数据，
只能用来熟悉流程，**不能当成绩**。界面上会有黄色提示条。
填好 API Key 后点「重新打分」即可换成真实评阅。


【微信群记录怎么复制】
在微信里长按某条消息 → 选择「多选」→ 勾选要评阅的消息 → 点「转发/复制」→ 复制，
然后整段粘贴到工具里。工具能识别这几种常见格式：

  张三                     张三：今天的课……          [2024-05-20 14:30] 张三：……
  2026年09月26日 13:53     李四：我也学到了……
  今天的课让我理解了……      （手机端复制单条）        （带时间戳的格式）

昵称带 (wxid_xxx)、带群备注（张三-计科2201）、带表情，都能正常识别。
时间行、系统提示（撤回/入群/拍一拍）、[图片][表情] 会自动跳过。


【学生用的是网名，成绩表要真名怎么办】
把名单粘到「学生名单」框里，直接在 Excel 里选两列复制粘贴就行：

  姓名,学号,群昵称
  张三,2023123456,赢赢
  李四,2023123457,logic

列顺序随意（有表头就行）。工具会自动把「赢赢」换成「张三」并带上学号。
姓名对不上的会在「解析提示」列标出来，不会把人弄丢。


【关于防抄袭、防 AI 代写】
工具会给每份心得做三件事，结果都写在结果表的「风险提示」列：
1. 和同批次所有同学的正文两两比对，算出雷同度，并指出重合的句子；
2. 检测套话密度、句子长度是否过于均匀、有没有只有上过课才知道的具体细节；
3. 让 AI 逐条判断，并且**必须引用原文原句**作为证据，证据不足时必须判"正常"。

重要：这些只是**提示**，不是判罚。工具的立场是"帮您发现可疑，由您来定"。
点开每行的「详情」可以看到完整的判断依据和原文，请以您的判断为准。


【关闭程序】
- 直接关掉那个黑色窗口，就等于退出程序；
- 或者点网页右上角的「退出程序」按钮。
（只关浏览器标签页不会退出程序，黑色窗口还在就说明程序还在跑。）


【常见问题】
Q：浏览器没有自动打开？
A：黑色窗口里有一行「界面地址：http://127.0.0.1:xxxx/」，
   把这行地址复制到浏览器地址栏打开即可。

Q：提示「API Key 被拒绝」？
A：检查 Key 有没有复制全（前后不要有空格），以及余额是否充足。

Q：打分很慢？
A：正常。每份心得要单独问一次 AI，30 份大约 1～3 分钟。
   可以在设置里把"并发数"调大一点（默认 4，最快可到 16）。

Q：有几份显示"打分失败"？
A：多半是网络抖动或额度不足。点「重新打分」再跑一次即可，
   已经打好的分数不会丢。

Q：能换别家的大模型吗？
A：可以。只要服务商提供兼容 OpenAI 的接口，
   在设置里改「接口地址」和「模型名」就行（例如通义、智谱等）。

Q：成绩表长什么样？
A：导出的 Excel 有三张表：
   「成绩表」——一行一个学生，各维度分、总分、风险、评语；
   「评分规则」——本次用的是哪套规则，存档用；
   「雷同比对」——本批次两两相似度，复核抄袭用。
